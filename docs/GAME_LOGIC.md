# Game logic

## ルーレットの入力

ジャンルはお菓子／おもちゃ／ゲーム、BETは1〜5です。選択ジャンルとBETはメモリ内だけで、初期値はお菓子・BET1です。回転中は再実行、ジャンル変更、BET変更を止めます。

## 消費と抽選

回転開始時に所持チケットがBET未満なら停止します。足りる場合はBET分を先に減算し、重み合計に対する一様乱数で1セグメントを選びます。確率は `weight / totalWeight` です。全BET表は `CORE_LOGIC.md` にあります。

## 結果

- 正のポイント: 選択PAYへ表示値を加算。
- 通常0P: PAYは変えず、チケットを1枚返却。
- ハピチャン: PAYは変えず、ハピチャンカードを1枚付与。
- 予約カードあり: 開始時にカードを1枚消費し、抽選結果へ+1P。0Pまたはハピチャンでも+1Pされる。

抽選結果、チケット返却、カード獲得・使用を1本の一般履歴文として保存します。回転アニメーション後（約3.7秒後）に結果を保存するため、その間のページ再読込では開始時のチケット減算自体も未保存です。

## ハピチャンカード

現在使える導線は抽選前の予約です。予約状態は保存されず、ページ再読込で解除されます。`useHappyChanceCard` という抽選後処理はコードにありますが、結果オブジェクトの `canUseCard` がfalse固定のため到達不能です。

## 安全上の位置づけ

画面内のルール説明は、本物のお金、課金、賭けごとではなく、お手伝いチケットによる家族内のごほうびルーレットと明記しています。
