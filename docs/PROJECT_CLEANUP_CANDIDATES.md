# Project cleanup candidates

ここに挙げるものは削除候補であり、削除確定ではありません。参照元・運用・デプロイを確認するまで削除しないでください。今回の整理では一切削除していません。

| 候補 | 理由 | 要確認事項 |
|---|---|---|
| `dist/` | Git ignoredのビルド生成物。`npm run build` で再生成される | デプロイ／手動確認でローカル成果物を使っていないか |
| `dist/homecasino.html.txt` | 現在のソース版とSHA-256が異なり、古い生成物の可能性 | 次回正規ビルド後に一致するか |
| `homecasino.html.txt` | 現在は `index.html` と完全一致する重複ファイル | 「元データ互換用コピー」を必要とする外部運用があるか |
| `useHappyChanceCard` と関連委譲クリック | `canUseCard` が常にfalseで現行導線から到達不能 | 結果後使用方式を復活させる予定があるか |
| `Task.status=inProgress` / `startedAt` 関連 | 現行UIに開始操作がない | 将来の開始・作業中機能で必要か、旧データ互換に必要か |
| `public/audio/.gitkeep` | ディレクトリ保持用。音声ファイル配置後は不要になり得る | 音声導入予定 |
| 空の `.agents/` | 現在ファイルなし | 外部ツールが作業用に利用していないか |

## 確認結果

- 未使用画像: 画像ファイル自体なし。インラインSVG/CSSは表示に使用。
- 未使用音声: 音声実ファイルなし。参照予定ファイル名のみ存在。
- 古いバックアップ: 明示的なバックアップファイルなし。
- 重複ファイル: `index.html` と `homecasino.html.txt` が同一。
- build生成物: `dist/` 全体。
- cache: プロジェクト内にキャッシュディレクトリなし。
- `node_modules/`: 存在しない。

## 整理時の注意

`scripts/build.js` は実行時に `dist/` を再帰削除して再作成します。ビルドを行う前に、`dist/` が生成物だけであることを確認してください。
