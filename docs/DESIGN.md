# Design

## 世界観

HAPICHIKEは、アメリカンPOPとラスベガス風のルーレット演出を、子ども向けの安全なお手伝い体験に置き換えています。紙チケット、スターコイン、PAY、ごほうびSHOP、ショーマン風マスコット、電飾看板風の要素を一貫して使用します。「ハピチャンカード」はピンクのハート付きボーナスカードとして表現されます。

## 色とタイポグラフィ

主要CSS変数は ink `#273043`、sky `#81d4fa`、mint `#5ee7a5`、rose `#ff6f91`、sun `#ffd166`、violet `#a78bfa`、felt `#16a085` です。白・クリーム・赤・黄・濃紺の強い縁取り、グラデーション、影を多用します。

本文フォントは `Yu Gothic`, `Meiryo`, `system-ui`, `sans-serif`。ロゴは `Arial Rounded MT Bold` を先頭にします。外部Webフォントは読み込んでいません。

## UI要素

- ボタン: 太字、丸角、濃色の境界と影。主要・副次・危険・状態別の色を持つ。
- カード: お手伝い、PAY、ごほうび、履歴を白系カードで分離する。
- チケット: TICKET文字、切符形状、🎫／🎟️で残高・報酬を表示する。
- スターコイン: 黄色の星とコイン色。5枚交換と「ありがとうスター」入力をステータス領域に置く。
- ルーレット: 緑のカジノテーブル、円形ホイール、BETボタン、結果チップを使用する。
- ハピチャンカード: ピンク系パネルと💖で、所持・予約・獲得を区別する。
- モーダル: 情報、履歴検索、一括選択、親管理に共通のバックドロップを使う。
- フィードバック: トースト、紙吹雪、効果音、結果色を併用する。

## レスポンシブとアクセシビリティ

複数のメディアクエリで、狭い画面ではグリッドやルーレットダッシュボードを1列化します。`clamp()` を多用して文字・余白を調整します。`prefers-reduced-motion: reduce` ではアニメーション時間を実質ゼロにします。主要モーダルには `role="dialog"` / `aria-modal`、通知には `aria-live` があります。ただしフォーカストラップなど完全なモーダルアクセシビリティは確認できません。

## 使用中アセット

- ロゴ、街並み、マスコット、コイン、チケット: `index.html` 内のCSS／インラインSVG
- アイコン: 絵文字
- 紙吹雪: JavaScriptで一時DOM要素を生成
- 音声参照: `public/audio/*.mp3` 9種。ただし実ファイル未配置
- 音声フォールバック: Web Audio APIで生成する短い音とBGM

外部画像や画像ファイルの参照は確認できません。
